# Security policy

Model Optimizer Lite is an instruction-only skill. It has no executable helper,
network connection, hook, background process, or provider credential.

Report a security issue through a private GitHub security advisory. Do not put
credentials, private transcripts, personal data, or unpublished project material
in an issue or example prompt.

The skill does not grant authority to change settings, start another AI session,
send data to a provider, or perform work beyond the user's request.
